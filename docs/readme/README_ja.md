# VoxQueue — 日本語

OpenAI 互換の `/v1/audio` サーバー（Piper、VoiceStudio、Aether Voice Hub）向けのバッチ音声合成。

---

## クイックスタート

**Windows** — `publish/windows/VoxQueue.exe` をダウンロードして実行。インストール不要。

**Linux** — `publish/linux/VoxQueue`、またはソースから:

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r build/requirements.txt
python3 -m voxqueue
```

1. **設定 → 接続** — サーバーアドレス、既定値 `http://127.0.0.1:3900`
2. **更新** — 音声リストを読み込む
3. モードを選び、テキストを貼り付け（または `.txt` をフィールドにドロップ）
4. **テキストを解析** — パーサーが検出したセリフ数を表示
5. **開始**

各モードのサンプルは `samples/` にあります。

---

## 3つのモード

モードが決めるのは**1つだけ**: テキストをセリフに分割する方法とファイル名の付け方です。

| モード | 入力 | 出力 |
|---|---|---|
| **学習用** | 1行 = 1セリフ | `wav/0000.wav` + `metadata.csv` |
| **吹き替え** | `名前: セリフ` | `voices/名前/名前_0000_2.41s.wav` |
| **バッチ** | `###` で区切られたブロック | `wav/0000.wav` + `0000.txt` |

---

## 発音マーカー

TTS モデルは綴りではなく文字を読みます。`Aether` は「A-e-ther」になります。`2024` は一文字ずつ読まれます。数詞は基本形にしか展開されないため、活用した形はすべて誤りになります。エンジンには発音表記を、転記には正しい綴りを渡します:

```
{Eter|Aether} はオンラインです。
西暦{にせんにじゅうよん|2024}年。
{ピーエム|PM} が報告書を送りました。
```

- **1つ目**の形式が TTS エンジンに渡る — 実際に発音される
- **2つ目**の形式が `metadata.csv` と `.txt` 転記に入る

### 規則

| 記法 | 効果 |
|---|---|
| `{発音\|表記}` | 1つ目を発音し、2つ目を書き込む |
| 縦棒のない `{テキスト}` | そのまま残る — マーカーではない |
| 空の側（`{\|テキスト}`、`{テキスト\|}`） | そのまま残る — 何も削除されない |
| `}` のない `{` | そのまま残る |
| 不正なマーカー | テキストを壊さない |

表記側は**不可侵**です: 同じ活用、同じ綴り、同じ句読点。

確定した単語リストは言語ごとに異なります — 参照音声を聴いて作成してください。

## AI モデル用のコピー可能なプロンプト

任意のアシスタントに貼り付けると、VoxQueue がそのまま受け取れるスクリプトが得られます。

```
VoxQueue に取り込む `.txt` ファイルを作成してください。1行 = 1セリフです。自然な
日本語で書いてください。音声合成が誤って読む箇所 — 外来の固有名詞、複数桁の数
字、略語、記号、単位 — では `{発音|表記}` のマーカーを使ってください。例:
`{Eter|Aether}`、`{にせんにじゅうよん|2024}`。右側の表記は、転記に残すべきも
のと完全に同一で、元の活用や助詞を保ってください。普通の単語、1桁の数字、自
然に読める日付には付けないでください。翻訳しないでください。原文の文法を直さ
ないでください。最後に、発音に自信がなかった行をすべて列挙してください。
```

---

ゼロからなら最低 5〜8 時間の音声が必要です。8〜10 時間を目標にしてください。

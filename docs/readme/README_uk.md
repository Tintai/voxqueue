# VoxQueue — Українська

Пакетний синтез мовлення для будь-якого сервера, сумісного з OpenAI `/v1/audio` (Piper, VoiceStudio, Aether Voice Hub).

---

## Швидкий старт

**Windows** — завантажте `publish/windows/VoxQueue.exe` і запустіть. Нічого встановлювати не треба.

**Linux** — `publish/linux/VoxQueue`, або з джерел:

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r build/requirements.txt
python3 -m voxqueue
```

1. **Налаштування → Підключення** — адреса сервера, типово `http://127.0.0.1:3900`
2. **Оновити** — завантажує список голосів
3. Виберіть режим, вставте текст (або перетягніть `.txt` у поле)
4. **Розібрати текст** — покаже, скільки реплік знайшов парсер
5. **Старт**

Приклади для кожного режиму — у `samples/`.

---

## Три режими

Режим вирішує **одну річ**: як текст ділиться на репліки і як називаються файли.

| Режим | Вхід | Вихід |
|---|---|---|
| **Навчання** | один рядок = одна репліка | `wav/0000.wav` + `metadata.csv` |
| **Дубляж** | `ПЕРСОНАЖ: діалог` | `voices/ПЕРСОНАЖ/ПЕРСОНАЖ_0000_2.41s.wav` |
| **Пакет** | блоки через `###` | `wav/0000.wav` + `0000.txt` |

## Маркери вимови

Модель читає літери, а не правопис. `Aether` виходить як «А-е-ther». `2024` читається по літерах. Числа розкриваються в початковій формі, тому будь-яка відмінювана форма хибна. Дайте рушію фонетичний запис, зберігши правильний у транскрипті:

```
{Eter|Aether} у мережі.
Рік {дві тисячі двадцять четвертий|2024}.
{Пі Ем|PM} надіслав звіт.
```

- **перша** форма йде до рушія TTS — вона вимовляється
- **друга** форма йде до `metadata.csv` і в транскрипт `.txt`

### Правила

| Запис | Дія |
|---|---|
| `{вимовляється\|пишеться}` | вимовляє перше, записує друге |
| `{текст}` без риски | залишається буквально — не маркер |
| порожній бік (`{\|текст}`, `{текст\|}`) | залишається буквально — нічого не видаляється |
| `{` без `}` | залишається буквально |
| неправильний маркер | ніколи не знищує текст |

Письмова форма **недоторканна**: той самий відмінок, той самий правопис, та сама пунктуація.

Перелік слів залежить від мови — складіть його, слухаючи еталонний голос.

## Готовий промпт для моделі ШІ

Вставте в будь-якого асистента, щоб отримати скрипт, який VoxQueue прийме напряму.

```
Підготуй файл `.txt` для імпорту у VoxQueue. Один рядок = одна репліка. Пиши
природною українською. Скрізь, де синтезатор мовлення прочитає неправильно —
іноземні імена, багатозначні числа, абревіатури, символи, одиниці — використай
маркер `{вимова|написання}`, наприклад `{Eter|Aether}` або
`{дві тисячі двадцять четвертого|2024}`. Форма праворуч має бути саме тим, що
потрапить у транскрипт, з початковим відмінком. Не позначай звичайні слова,
однозначні числа й дати, які читаються природно. Не перекладай. Не виправляй
граматику у вихідному тексті. Наприкінці перелічи всі рядки, у вимові яких ти
не впевнений.
```

---

From scratch, 5–8 hours of audio is the minimum; aim for 8–10.

# VoxQueue — Русский

Пакетный синтез речи для любого сервера, совместимого с OpenAI `/v1/audio` (Piper, VoiceStudio, Aether Voice Hub).

---

## Быстрый старт

**Windows** — скачайте `publish/windows/VoxQueue.exe` и запустите. Ничего устанавливать не нужно.

**Linux** — `publish/linux/VoxQueue`, или из исходников:

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r build/requirements.txt
python3 -m voxqueue
```

1. **Настройки → Подключение** — адрес сервера, по умолчанию `http://127.0.0.1:3900`
2. **Обновить** — загружает список голосов
3. Выберите режим, вставьте текст (или перетащите `.txt` в поле)
4. **Разобрать текст** — покажет, сколько реплик нашёл парсер
5. **Старт**

Примеры для каждого режима — в `samples/`.

---

## Три режима

Режим решает **одну вещь**: как текст делится на реплики и как называются файлы.

| Режим | Вход | Выход |
|---|---|---|
| **Обучение** | одна строка = одна реплика | `wav/0000.wav` + `metadata.csv` |
| **Дубляж** | `ПЕРСОНАЖ: диалог` | `voices/ПЕРСОНАЖ/ПЕРСОНАЖ_0000_2.41s.wav` |
| **Пакет** | блоки через `###` | `wav/0000.wav` + `0000.txt` |

## Маркеры произношения

Модель читает буквы, а не орфографию. `Aether` превращается в «А-е-ther». `2024` произносится по буквам. Числа раскрываются в начальной форме, поэтому любая склонённая форма неверна. Дайте движку фонетическую запись, сохранив правильную в транскрипте:

```
{Eter|Aether} в сети.
Год {две тысячи двадцать четвёртый|2024}.
{Пи Эм|PM} отправил отчёт.
```

- **первая** форма идёт в движок TTS — она произносится
- **вторая** форма идёт в `metadata.csv` и в транскрипт `.txt`

### Правила

| Запись | Действие |
|---|---|
| `{произносится\|пишется}` | произносит первое, записывает второе |
| `{текст}` без черты | остаётся буквально — не маркер |
| пустая сторона (`{\|текст}`, `{текст\|}`) | остаётся буквально — ничего не удаляется |
| `{` без `}` | остаётся буквально |
| неверный маркер | никогда не уничтожает текст |

Письменная форма **неприкосновенна**: то же склонение, та же орфография, та же пунктуация.

Список слов зависит от языка — составьте его, слушая эталонный голос.

## Готовый промпт для модели ИИ

Вставьте в любого ассистента, чтобы получить скрипт, который VoxQueue примет напрямую.

```
Подготовь файл `.txt` для импорта в VoxQueue. Одна строка = одна реплика. Пиши
на естественном русском. Везде, где синтезатор речи прочитает неправильно —
иностранные имена, многозначные числа, аббревиатуры, символы, единицы —
используй маркер `{произношение|написание}`, например `{Eter|Aether}` или
`{две тысячи двадцать четвёртого|2024}`. Форма справа должна быть ровно тем,
что попадёт в транскрипт, с исходным склонением. Не помечай обычные слова,
однозначные числа и даты, которые читаются естественно. Не переводи. Не
исправляй грамматику в исходном тексте. В конце перечисли все строки, в
произношении которых ты не уверен.
```
